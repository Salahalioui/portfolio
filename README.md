# Portfolio Application — Salah Alioui

Personal portfolio web application for Dr. Salah Alioui (PhD Sports Science Researcher & Full-Stack AI Software Engineer).

## 🚀 Tech Stack

- **React 19** with TypeScript
- **Tailwind CSS v4** + Custom Glassmorphism System
- **Lucide Icons** for modern iconography
- **Vite 8** for lightning-fast bundling & HMR

## 🌟 Featured Projects Included

1. **VolleyLens** (Tauri 2 Rust Desktop Suite)
2. **StyleAI / Virtual Try-On** (Multimodal Gemini 2.5 AI Assistant)
3. **Ikhtiyar-DZ** (Offline PWA Sports Scouting System)
4. **Academic AI Writing Assistant** (Bilingual Research Editor)
5. **PE Inspector Platform** (Supabase + Arabic RTL Oversight Portal)
6. **ASJP Research Tool** (Paper Scraper & PRISMA Synthesizer)

## 🛠️ Local Development

```bash
npm install
npm run dev
```

## 🌐 Deploy to Vercel

```bash
npm run build
```
